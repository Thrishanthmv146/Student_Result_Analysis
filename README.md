# 📌 Student Performance Analytics

A Python-based project that analyzes student academic performance using Pandas and NumPy. It calculates total and average marks and identifies the highest, average, and lowest performers.

## 🚀 Features

- ✅ Calculates total marks for each student.
- ✅ Calculates average marks across subjects.
- ✅ Identifies the highest-performing student.
- ✅ Identifies the student closest to the class average.
- ✅ Identifies the lowest-performing student.
- ✅ Displays selected students with their IDs and names.
- ✅ Uses Pandas DataFrames for organized results.

---

- 🐍 Python

## 📂 Dataset

The dataset contains:

- Student ID
- Student name

- Mathematics marks
- Attendance percentage

## 📌 Usage

1. Open the Python file or notebook.
2. Make sure the dataset is available.
